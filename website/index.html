Panel guide

Explain the model
in three moves.

A concise narrative for your supervisor or evaluation panel.

01

Why this matters

Deleting a database row is not the same as erasing influence from an AI pipeline. DFI makes hidden residue visible across four surfaces.

02

How it works

Each layer uses a specialized probe: fuzzy matching, database residue scanning, vector retrieval leakage, and model MIA/extraction evidence.

03

What the score means

The result is an empirical, auditable lower-bound-style signal — not proof of deletion or a differential-privacy guarantee.

SAY THIS CLEARLY

The current implementation validates the DFI measurement framework on a controlled synthetic dataset. Real production connectors and model-specific attacks are the next research stage.
